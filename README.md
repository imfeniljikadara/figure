# Figure

Create beautiful diagrams and sketches directly in VS Code! Figure is a powerful drawing extension that brings the full capabilities of Excalidraw right into your editor.

## Features

- Full-featured drawing interface
- Save/Load .figure files
- Dark/Light theme support matching VS Code
- Keyboard shortcuts for saving (Ctrl/Cmd + S)

## Installation

1. Clone this repository
2. Run `npm install`
3. Press F5 to start debugging

## Usage

1. Open the command palette (Ctrl/Cmd + Shift + P)
2. Type "New Figure Sketch" and select it
3. Start drawing!

### Saving Your Work

- Press Ctrl/Cmd + S to save your drawing as a .figure file
- Your drawings are saved in a format compatible with Excalidraw

## Requirements

- VS Code 1.85.0 or higher
